🚀 Ang Aking Unang Repo

Ang website na ito ay nakatira sa loob ng isang repo. Hindi ito basta files — may kasaysayan ito ng bawat pagbabagong ginawa ko para sa'yo.

❓ Ano ba ang repo?

Tatlong konsepto lang ang kailangan mong tandaan:

📦

Repo

Parang smart folder na naaalala ang bawat bersyon ng iyong proyekto — time machine para sa files.

✅

Commit

Bawat "save point". May mensahe ito, petsa, at kung sino ang gumawa. Ito ang bumubuo ng history.

🌿

Branch

Parallel na bersyon ng proyekto. Dito ka nag-e-eksperimento nang hindi nasisira ang main.

📜 Tunay na kasaysayan ng repo na ito

Ito ang totoong git log — kinukuha nang live mula sa nakatagong .git folder ng repo na ito.

Nilo-load ang history…

Wala ka pang ginagawang commit. Subukan mo ang pindutan! 👆

📁 Ano ang laman ng repo na ito?

Ito ang mga file na nakikita mo — bawat isa ay may papel sa proyekto.

📘
README.md dokumentasyon Ang cover page — una itong binabasa ng mga tao
🌐
index.html website Ang istraktura ng pahinang binabasa mo ngayon
🎨
style.css disenyo Ang mga kulay, layout, at animation
⚡
script.js logic Ang utak — ginagawang gumagana ang pahina
🐍
server.py server Mini server na naghahatid ng site na ito sa browser mo
🗄️
.git/ nakatago Dito nakatira ang BUONG history ng repo

🧪 Subukan mo sa totoong buhay

Kapag may repo ka sa computer mo, ganito mo makikita ang kasaysayan:

$ git log --oneline
abc1234 (HEAD -> main) 🎉 Feature: lumilipad na emoji tuwing may commit
def5678 🖥️ Dinagdag ang mini server: server.py
a1b2c3d ⚡ Ginawang interactive: script.js
e4f5a6b 🎨 Pinaganda ang disenyo: style.css
c7d8e9f 🌱 Unang pahina: index.html
0123abc 📝 Simula: ginawa ang README (paliwanag ng proyekto)

(Ito ay halimbawa lang — ang tunay na listahan ay nasa itaas, galing mismo sa .git ng repo na ito.)
Sa GitHub, ang repo ay naka-store sa cloud at pwedeng i-share sa buong mundo. 🌍

Gawa nang may 💚 bilang iyong unang hakbang sa mundo ng Git at GitHub.
