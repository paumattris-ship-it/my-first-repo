# 🚀 Ang Aking Unang Repo

Kumusta! 👋 Ito ang kauna-unahang **repository (repo)** mo. Ginawa ko ito mula sa wala para makita mo mismo kung paano nabubuo ang isang proyekto.

## ❓ Ano ba ang "repo"?

Ang repo ay parang **smart folder** sa internet. Hindi lang basta folder —
naaalala nito ang **lahat ng bersyon** ng bawat file, kaya pwede kang bumalik
sa anumang sandali ng proyekto, parang time machine. ⏪

- **Commit** ✅ — Bawat "save point" ng proyekto. May mensahe, petsa, at kung sino ang gumawa.
- **Branch** 🌿 — Parallel na bersyon ng proyekto kung saan pwedeng mag-eksperimento nang hindi nasisira ang pangunahing bersyon.
- **Merge** 🔀 — Pagsasama ng trabaho mula sa isang branch pabalik sa main.

## 📁 Ano ang laman ng repo na ito?

| File | Para saan |
|---|---|
| `index.html` | Ang website mismo — ang istraktura |
| `style.css` | Ang disenyo at mga kulay |
| `script.js` | Ang interaktibidad (mga pindutan, animation) |
| `server.py` | Mini web server para ma-preview ang site |
| `README.md` | Itong file — ang "cover page" ng proyekto |
| `.gitignore` | Listahan ng mga file na hindi dapat isama sa repo |
| `.git/` | Nakatagong folder kung saan nakatira ang buong history |

## 🖥️ Paano patakbuhin?

```bash
python3 server.py
```

Tapos buksan sa browser ang `http://localhost:8000`

## 📜 Tingnan ang history

```bash
git log --oneline
```

Dito mo makikita ang lahat ng commits — sino ang gumawa, kailan, at bakit.
